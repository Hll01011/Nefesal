# 🌿 Nefes Al

> Her gün biraz daha iyi. Her yerde biraz daha özgür.

Sağlık, kişisel gelişim ve seyahat üzerine Türkçe bir blog.  
Sıfırdan HTML/CSS ile yazıldı. GitHub Pages üzerinde yayınlanıyor.

## Klasör Yapısı

```
nefesal/
├── assets/
│   ├── css/       → stil dosyaları
│   ├── js/        → javascript
│   └── img/       → görseller
├── beden/         → sağlık & beslenme yazıları
├── zihin/         → kişisel gelişim yazıları
├── yol/           → seyahat yazıları
├── hakkimda/      → hakkımda sayfası
└── index.html     → ana sayfa
```

## Yayın

GitHub Pages → `https://kullaniciadi.github.io/nefesal`  
Domain → `https://nefesal.com.tr` *(yakında)*

## Teknoloji

- Saf HTML5 + CSS3 + Vanilla JS
- Google Fonts: Lora + DM Sans
- Responsive tasarım
- Harici kütüphane yok
